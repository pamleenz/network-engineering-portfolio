# Cisco DMVPN Phase 3 + IKEv2/IPsec reference

HUB Tunnel0:
 ip address 10.255.100.1 255.255.255.0
 no ip redirects
 ip nhrp authentication DMVPN100
 ip nhrp map multicast dynamic
 ip nhrp network-id 100
 ip nhrp redirect
 tunnel source Ethernet0/0
 tunnel mode gre multipoint
 tunnel key 100
 tunnel protection ipsec profile DMVPN-IPSEC-PROFILE
 no ip split-horizon eigrp 100

SPOKE template:
 ip nhrp authentication DMVPN100
 ip nhrp map 10.255.100.1 192.0.2.2
 ip nhrp map multicast 192.0.2.2
 ip nhrp nhs 10.255.100.1
 ip nhrp network-id 100
 ip nhrp shortcut
 tunnel mode gre multipoint
 tunnel key 100
 tunnel protection ipsec profile DMVPN-IPSEC-PROFILE

IKEv2/IPsec:
crypto ikev2 proposal DMVPN-IKEV2-PROP
 encryption aes-cbc-256
 integrity sha256
 prf sha256
 group 14
crypto ikev2 policy DMVPN-IKEV2-POLICY
 proposal DMVPN-IKEV2-PROP
crypto ipsec transform-set DMVPN-TS esp-aes 256 esp-sha256-hmac
 mode transport
crypto ipsec profile DMVPN-IPSEC-PROFILE
 set transform-set DMVPN-TS
 set ikev2-profile DMVPN-IKEV2-PROFILE
