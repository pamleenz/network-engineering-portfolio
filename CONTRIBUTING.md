# Portfolio Module Convention

Each completed engineering module should normally contain:

- `README.md` — scenario, design intent, implementation summary, outcomes
- `topology/` — final topology or architecture diagram
- `configs/` — sanitized final configurations
- `docs/verification.md` — commands and evidence used to verify the design
- `docs/troubleshooting.md` — break/fix scenarios, root cause, recovery and lessons learned

Do not publish real passwords, API keys, private keys, customer identifiers, production IP data, or other sensitive information.
